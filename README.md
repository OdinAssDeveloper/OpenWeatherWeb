# OpenWeatherWeb

SPA на React + TypeScript + Vite

Сайт: https://odinassdeveloper.github.io/OpenWeatherWeb/

## Возможности

- Кнопка «Добавить город» открывает отдельное окно поиска через Geocoding API OpenWeather.
- Выбранные города сохраняются в localStorage браузера (`openweatherweb:saved-cities`) и отображаются отдельными карточками. При каждом запуске SPA/PWA погода для всех сохранённых городов запрашивается автоматически.
- Повторное добавление одного места исключено по координатам; удаление города требует подтверждения. Список синхронизируется между вкладками с общим хранилищем.
- Погода загружается независимо для каждого города, с отдельными сообщениями об ошибках и кнопками повторного запроса/обновления. При ошибке город остаётся в списке.
- На телефоне главный экран подстраивается под доступную высоту: приветственный блок скрыт, все показатели выбранного города помещаются на экране. Переключатель сверху позволяет выбрать другой сохранённый город; при добавлении открывается новый город. Все города обновляются при запуске, переключение не повторяет запросы. В альбомной ориентации показатели располагаются в две колонки. На компьютере сохраняется список всех карточек. Окна поиска и настроек прокручиваются внутри при необходимости.
- Выбор среди одноимённых мест; сообщения для пустого ввода и ненайденного города.
- Температура, влажность, ветер, давление, видимость, облачность, восход и закат по местному времени города.
- Адаптивный интерфейс на русском. Для поиска и загрузки погоды нужен личный API-ключ OpenWeather. Демонстрационный режим отсутствует.
- Обработка неверного ключа, лимитов API, сетевых ошибок и отмены устаревших запросов.

## Запуск

Нужен Node.js 22.12+ (или 24).

```bash
npm install
npm run dev
```

Проверки и сборка: `npm test` и `npm run build`.

## Ключи и Keyring

Ключ не включается в исходники, .env, сборку, GitHub Secrets или публичные артефакты. После «Подключить» личный ключ сохраняется открытым текстом в localStorage этого браузера (запись openweatherweb:openweather-api-key) и восстанавливается после перезагрузки SPA или перезапуска PWA. Он передаётся только https://api.openweathermap.org. В профиле браузера, поддерживающем общее хранилище для сайта и PWA, используется одна запись; другой браузер, устройство или изолированная установка могут иметь отдельное хранилище.

Для удаления откройте настройки ключа и нажмите «Удалить сохранённый ключ» либо очистите данные этого сайта в браузере. Очистка только HTTP-кэша не всегда очищает localStorage. Изменение/удаление синхронизируется между открытыми вкладками с общим хранилищем. При блокировке localStorage приложение сообщает об ошибке сохранения/удаления. В приватном режиме и при автоматической очистке/вытеснении данных браузером сохранность не гарантируется.

Это изменение сделано по явному запросу пользователя для данного SPA/PWA: localStorage не зашифрован и доступен JavaScript того же origin и расширениям с соответствующим доступом. Service worker не кэширует ключи или ответы API. Аналитика не используется.

На Ubuntu стандарт хранения — GNOME Keyring / Secret Service. Запись можно создать в своём терминале:

```bash
secret-tool store --label="OpenWeatherWeb OpenWeather" project OpenWeatherWeb service openweather
```

Введите ключ самостоятельно по запросу Password. Для уже существующей записи Test_proj используются атрибуты `project=Test_proj`, `service=openweather`. Не выводите секрет в терминал или логи; перенесите его в интерфейс самостоятельно через менеджер паролей. Доступ к локальному Keyring у опубликованного сайта отсутствует.

## GitHub Pages

Workflow .github/workflows/deploy.yml запускает тесты, TypeScript и production-сборку, затем публикует dist. В Settings → Pages выбран источник GitHub Actions. Для пути репозитория установлен Vite base /OpenWeatherWeb/. Последующие push в main автоматически обновляют сайт.

## Установка как PWA

Откройте сайт по HTTPS и нажмите «Установить». В Chrome/Edge при доступности появится системный запрос; в остальных случаях приложение покажет инструкцию. На iPhone/iPad откройте Safari → «Поделиться» → «На экран Домой». На Android используйте меню Chrome → «Установить приложение». На компьютере используйте значок установки в адресной строке Chrome/Edge. Доступность зависит от браузера.

После первого успешного открытия production-версии service worker сохраняет только оболочку приложения (HTML, JavaScript, CSS, manifest, иконки). Интерфейс и сохранённый список городов открываются без интернета. Погодные данные не сохраняются; при отсутствии сети карточки показывают ошибку с возможностью повторить запрос. Свежая погода требует подключения к OpenWeather; ответы API, URL с параметрами и ключи не записываются в Cache Storage. Внешний шрифт офлайн заменяется системным.

Ключ и список городов сохраняются в localStorage и восстанавливаются при запуске PWA. Очистка данных сайта удаляет их; список не переносится автоматически между устройствами и браузерами. При появлении новой версии нажмите «Обновить» в уведомлении. Путь и область service worker ограничены /OpenWeatherWeb/, кэши других приложений не удаляются. В npm run dev service worker не регистрируется. npm run build генерирует версию кэша по содержимому сборки; npm run preview позволяет проверить production PWA локально.
